# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Email
[aryan.anand1806@gmail.com](mailto:aryan.anand1806@gmail.com) with the affected URL or
file, reproduction steps, and impact. Please allow reasonable time for a fix before
disclosing the issue publicly.

This is a static portfolio site and does not intentionally accept or store sensitive
user data. The contact form opens the visitor's local email client; it does not send
messages to a server.
