# Aryan Anand Portfolio

A newspaper-style React portfolio for Aryan Anand, built with Vite. The site presents selected work, project case files, certifications, experience, skills, and contact details in an editorial layout.

## Tech Stack

- React 19
- Vite
- React Router
- Lucide React icons
- Plain CSS
- ESLint

## Scripts

- `npm run dev` - start the local Vite server
- `npm run lint` - run ESLint
- `npm run build` - create a production build
- `npm run check` - run lint and build together
- `npm run preview` - preview the production build locally

## Deployment Metadata

The canonical deployment URL is hard-coded in `index.html`, `public/robots.txt`, `public/sitemap.xml`, and `src/data/newspaper.js`. Update those files together whenever the production domain changes.
